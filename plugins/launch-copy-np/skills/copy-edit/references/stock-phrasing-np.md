# Stock phrasing catalogue, Nepal edition (SP-01 to SP-24)

Patterns that make Nepali launch copy (English, Nepali or Romanized) longer, vaguer or less believable without telling the buyer anything. SP ids are for your own tracking; never show them to the user. Remove the pattern; do not replace it with another stock phrase. A pattern is a problem only when it carries no information. Examples use fictional brands from `example-brands.md`.

## Family 1. Empty openers and closers

| id | Pattern | Example (before → after) |
|---|---|---|
| SP-01 | Announcement opener | "Hami excited chhau announce garna…" / "We are thrilled to introduce…" → "Sathi Khata le pasal ko udharo hisab mobile ma rakhcha." |
| SP-02 | Greeting wall | "Namaste dai didi bhai bahini haru!!! 🙏🙏🙏" before any point → one short greeting at most, then the product |
| SP-03 | Grand-opening cliché | "Grand Opening Grand Offer!!!" with no offer stated → state the real offer: "Opening week: free delivery inside the valley till Mangsir 15" |
| SP-04 | Vague blessing closer | "Thank you for your love and support always ❤️" as the last line of a sales post → end with the next step: "Order garna Messenger ma 'Order' lekhnuhos." |

False positive: a warm greeting in a festival message or a thank-you post is fine; it is a problem only when it replaces the point.

## Family 2. Unearned emphasis

| id | Pattern | Example (before → after) |
|---|---|---|
| SP-05 | Hype superlative | "Nepal's No. 1", "best in Nepal", "sabai bhanda ramro", "unbeatable" → remove, or send to `copy-proof-check` |
| SP-06 | "100%" stack | "100% original 100% guaranteed 100% satisfaction" → the one real fact: "Authorized distributor of Pahadi Maha in Nepal" (if the user confirms) |
| SP-07 | "Sasto ra ramro" | "Sasto ra ramro", "best quality cheapest price", "सस्तो र राम्रो" → the real price and one quality fact: "Rs 650, 500 g, raw honey from Sindhupalchok" |
| SP-08 | ALL CAPS and !!! | "HURRY UP!!! LIMITED STOCK!!!" → normal case, real limit or none |
| SP-09 | Emoji walls | 🔥🔥🔥💯💯✅✅ → at most one or two emoji that carry meaning, if the brand voice allows |
| SP-10 | Empowerment verbs | "empower", "revolutionize", "unlock", "digital krantikari" → the plain verb: "lets you", "keeps", "sends" |

False positive: a superlative with a named, dated source is a claim to check, not a stock phrase.

## Family 3. Hidden information

| id | Pattern | Example (before → after) |
|---|---|---|
| SP-11 | "Price inbox ma" | "Price ko lagi inbox garnuhos" → the price in the post: "Rs 1,499 (delivery inside valley Rs 100)" unless the user has a reason to hide it |
| SP-12 | "Contact for details" | "Thap jankari ko lagi samparka garnuhos" with nothing else → the two facts buyers ask first (price, delivery or location), then the contact |
| SP-13 | Vague location | "Kathmandu ma available" → the real area or pickup point the user gives: "Pickup: Kupondole, Lalitpur" |
| SP-14 | Missing terms | "Exchange available" → the real term: "Size namilema 7 din bhitra exchange; delivery charge hamro" (only if the user says so) |

## Family 4. Padding shapes

| id | Pattern | Example (before → after) |
|---|---|---|
| SP-15 | Reflexive triple | "Fast, reliable and affordable" → the one fact that matters |
| SP-16 | Translated-twice copy | The same sentence in English then Nepali then Romanized, in one short post → pick one language per post or section, or a short bilingual pair only where the user asks |
| SP-17 | Hashtag spam | #nepal #kathmandu #onlineshopping #sale #offer #trending #viral … (20 tags) → 3–5 tags a real buyer or the brand uses |
| SP-18 | Restating paragraph | A second paragraph repeating the first in new words → cut |

## Family 5. Manufactured pressure

| id | Pattern | Example (before → after) |
|---|---|---|
| SP-19 | Fake deadline | "Offer aaja matra!" posted every day → a real end date or no deadline |
| SP-20 | Fake scarcity | "Only 3 pieces left" without a real count → real stock or nothing |
| SP-21 | Fear and shame | "Yo nakinne le pachutaunu hunecha", "Don't be left behind" → state what the product does |
| SP-22 | Rhetorical question chain | "Tired of…? Worried about…? Looking for…?" → one real question at most, then the answer |

## Family 6. Template and AI residue

| id | Pattern | Example (before → after) |
|---|---|---|
| SP-23 | Unfilled token | "[Brand Name]", "{{price}}", "XYZ" → flag for the user; never guess |
| SP-24 | Assistant or machine-translation residue | "Here is your caption", stiff literal Nepali ("तपाईंको व्यवसायलाई सशक्त बनाउनुहोस्" for "empower your business") → natural phrasing a Nepali shopkeeper would say: "तपाईंको पसलको हिसाब सजिलो बनाउँछ" |

False positive: a placeholder the user asked for is not residue.

## Quick test for any Nepali launch post

1. Can a buyer see the price, where it is available and how to order without messaging?
2. Is every number and promise real?
3. Would a buyer's uncle in Butwal understand it on the first read?
4. Does it sound like a person from the business, not a billboard or a translation?
