# Reply library (patterns to adapt)

Patterns only. Every bracketed item is replaced with the seller's real term or removed. Never send a bracket to a buyer. Examples use Romanized Nepali; adapt to the buyer's language.

| Shortcut | Situation | Pattern |
|---|---|---|
| /welcome | First message | "Namaste! [Brand] ma swagat cha. [Product] ko price [Rs …]. Delivery: valley bhitra [Rs …, … din], bahira [Rs …, … din]. Payment: [COD / eSewa / Khalti / QR]. Order garna naam, phone ra thegana pathaunus. Hami [hours] ma reply garchhau." |
| /price | "Price?", "kati ho?" | "[Product] — [Rs …]. [Variant prices if any]. Delivery [Rs …]. Order garna 'Order' lekhnuhos." |
| /delivery | Delivery time and charge | "Kathmandu Valley: [Rs …], [… din]. Valley bahira: [Rs …], [… din] ([courier]). Dashain/Tihar ma courier [cut-off date] samma matra." |
| /cod | Payment questions | "COD milcha [conditions]. eSewa/Khalti/QR bata pani tirna milcha." |
| /original | "Original ho?" | "[Real proof: authorized distributor of …, / hamro afnai workshop ma baneko, / warranty card sahit …]." |
| /size | Size help | "Tapai ko height ra weight (wa chest/waist naap) pathaunus, hami size suggest garchhau. Size namilema [exchange terms]." |
| /confirm | Order confirmation | "Order confirm garchhau: [item, variant] × [qty] = Rs […] + delivery Rs […] = jamma Rs […]. Thegana: [address], phone: [number]. [Expected day] samma pugcha. Thik cha bhane 'Yes' lekhnuhos." |
| /followup | Quiet after price | "Namaste! [Product] ko barema kei prashna cha bhane sodhnuhola. [Real offer end date if any]." (send once; a second only if the buyer engaged) |
| /bargain | Haggling | "Hamro price fixed ho, tara [real bundle/free delivery condition] cha." or simply hold politely. |
| /oos | Out of stock | "Mafi garnuhola, [item] ahile stock ma chaina. [Restock date if known / alternative]." |
| /complaint | Problem with order | "Dherai mafi chahanchhau. Photo pathaidinu huncha? Hami [real fix: exchange / refund / resend] garchhau." |
| /predispatch | Day before dispatch (COD) | "Bholi tapai ko [item] pathaudai chhau, jamma Rs […]. Ghar ma kohi hunuhuncha? Phone [number] ma rider le call garcha." |

Tips:
- Answer the question asked first, then one next step.
- Reply fast during launch week, including evenings; set honest hours in the auto-reply.
- After delivery: thank-you message and, a few days later, a review request from `claims-np.md` if the buyer seemed happy.
